# ثلاثاء الوفاء للشهداء

موقع عربي بصيغة سرد بصري لذكرى ٦ أيلول ٢٠١١، مع معرض صور ونموذج لإرسال كلمة وفاء.

**الموقع المنشور:** https://kakramah.github.io/martyrs-loyalty-tuesday/

هذا الموقع منشور، لكنه غير مدرج حالياً في فهرس الأعمال الرئيسي؛ توجد نسخة أخرى قريبة موضوعياً، ويحتاج اختيار موضع كل منهما إلى قرار تحريري.

## البنية

- `index.html`: النص والمشاهد والنموذج.
- `style.css` و`script.js`: العرض والتفاعل.
- `DESIGN.md`: مواصفات التصميم الحالية.
- `brand/` و`images/` و`fonts/`: الأصول.

## المعاينة

من جذر المستودع:

```sh
python3 -m http.server 8000
```

افتح `http://localhost:8000/` وراجع الصور والتصفح واستجابة النموذج دون إرسال بيانات تجريبية حقيقية. يعتمد إرسال النموذج على خدمة خارجية؛ افحص إعدادها عند تعديل النموذج، ولا تضع مفاتيح أو بيانات شخصية إضافية في التوثيق. لا توجد خطوة بناء في جذر المستودع.
